# Cityscapes Tiny · iBKD λ=0.25 · 2,000스텝 결과

2026-09-28 표기 통일: 초기 CE 비율은 L/16과 같은 **첫 step `β × guidance / CE`**입니다.
[환산 근거](../../initial_ce_ratio/README.md)에 로그와 계산법을 기록했습니다.
아래 비율은 근삿값이고 β·성능·선택 후보는 그대로입니다. 원본 JSON의 `initial_ratio`는
당시 25batch 중앙값 기준 목표값이며 첫 step 실측값으로 읽지 않습니다.

**상태: 8개 후보 모두 2,000스텝 학습과 전체 val 500장 평가 완료.** 2026-09-27 반영.

기존 v1의 완료된 후보 1~7번과, H200 **#844**에서 처음부터 다시 학습한 8번을 통합했습니다.
8번의 이전 1,995스텝 중단 실행은 평가 점수가 없는 이력으로만 보존합니다. 이번 결과는
**0→2,000스텝 새 실행**이며, 이전 checkpoint에서 5스텝만 이어 학습한 결과가 아닙니다.

## 공통 조건

- Student: Segmenter-Ti/16, decoder 1 layer; teacher: 공개 OpenMMLab DeepLabV3-R101-D8.
- Cityscapes fine train 2,975장 / 공식 val 500장 / 19 class. test·coarse는 사용하지 않습니다.
- Seed 1, crop512, batch8, FP32, SGD Nesterov LR0.01, 80,000스텝 LR schedule.
- 2,000스텝 고정 endpoint에서 전체 val을 한 번 평가합니다. 중간 최고점을 선택하지 않습니다.
- 실행 당시 1차 지표는 Pixel accuracy로 선언했고 동일 endpoint의 mIoU도 계산했습니다.
  2026-09-27 사용자 정정에 따라 **후속 후보 선정은 mIoU를 1차 기준**으로 합니다.
- iBKD warm-up 20epoch를 유지합니다. 모든 후보의 guidance는 종료 시에도 켜져 있습니다.

## 완결성 및 출처 확인

- 8개 모두 완료/선택/checkpoint step=2,000, val=500, 평가 class=19.
- 8개 모두 valid pixels=917,018,489. 클래스별 IoU 평균과 기록된 mIoU도 반올림 범위 안에서 일치합니다.
- Teacher 동결, checkpoint 저장·복원, 평가 중 student 불변 검사가 모두 통과했습니다.
- #844는 실제 실행 1개이며, 완료된 1~7번을 다시 실행하지 않았습니다.
- #844 준비 포함 총 시간은 **4,439.64초(약 74분)**, 학습·저장 구간은 3,869.2초, 전체 val은 103.11초입니다.
- v1/v2 설정 차이는 protocol ID와 시간 예산/저장 여유뿐입니다. 학습·평가 설정과 β는 같습니다.
- 이전 중단 8번과 새 8번에서 공통으로 보이는 80개 step(1~1,975)의 loss·CE·guidance·gradient norm을
  대조했습니다. 출력 정밀도에서 최대 차이는 약 0.000001이며 기존 허용오차(rtol=2e-5, atol=2e-6) 안입니다.
- 이 대조는 일부 step의 콘솔 수치 비교입니다. 첨부 로그에는 작업 사이의 전체 입력/상태 해시가 없어
  완전한 해시 재현성 검사로 표기하지 않습니다. 각 작업 내부의 보고된 identity 검사는 통과했습니다.
- deterministic warning은 남아 있습니다. `passed`는 이번 학습·평가와 저장 검사의 완료를 뜻하며
  CUDA의 모든 연산이 bitwise 결정적이라는 보장은 아닙니다.
