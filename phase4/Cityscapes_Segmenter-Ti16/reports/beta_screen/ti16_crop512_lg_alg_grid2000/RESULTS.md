# Cityscapes Tiny · LG/ALG · 2,000스텝 결과

**상태: LG 8개 + ALG 8개 모두 2,000스텝 학습과 전체 val 500장 평가 완료.** 2026-09-27 반영.
준비 포함 실행 시간은 **32,554.2초(9시간 2분 34초)**입니다. 첨부 로그는 마지막 65,000자여서
앞부분이 잘렸지만, 마지막 부모 JSON에는 16개 결과가 온전히 남아 있습니다.

## 조건과 결과

Tiny·공개 OpenMMLab DeepLabV3-R101 teacher·fine train 2,975장·crop512·batch8·decoder1·
FP32·seed1·SGD LR0.01·80,000step LR schedule을 사용했습니다. test는 사용하지 않았습니다.
각 후보를 새로 초기화해 학습하고 고정 2,000step에서 전체 val을 평가했습니다.

두 방법의 accuracy/mIoU가 콘솔 정밀도에서 같으므로 아래 표는 **LG와 ALG에 각각 적용**됩니다.
JSON에는 각 실행의 수치, 19 class IoU, 궤적 요약, 시간과 검사 결과를 따로 보존했습니다.

## ALG 종료 여부와 비교 검사

- **ALG warm-up=0**입니다. 가장 빠른 종료 가능 step은 745이지만 반드시 그때 끄는 것은 아닙니다.
- 이번 8개 ALG 모두 2,000step까지 `guidance_active=true`, `stop_epoch/step=null`이므로
  실제 가이던스 종료는 일어나지 않았습니다. 현재 결과는 ALG가 종료된 뒤의 효과를 보여주지 않습니다.
- 각 β의 LG/ALG 2,000개 step 비교는 기존 허용오차(rtol=2e-5, atol=2e-6) 내에서 전부 통과했습니다.
  일부 표시된 CE/궤적 수치에 미세 차이가 있으므로 학습 상태가 bitwise 동일하다고 표현하지 않습니다.
- 초기 student/teacher/adapter와 관측 입력 prefix, 방법/β 목록의 보고된 검사가 모두 통과했습니다.
- 16개 모두 checkpoint step=2,000, 저장·복원 검사 통과, teacher 동결 및 평가 중 student 불변입니다.
- 16개 모두 valid pixels=917,018,489이며, class IoU 평균과 mIoU도 출력 반올림 범위에서 일치합니다.
- 각 실행에 결정성 경고 2,000건이 기록됐지만 실패/중단/미실행 후보는 없습니다.
  이번 로그로 관측한 비교 검사의 통과를 확인했으며, 모든 CUDA 연산의 완전한 결정성을 보장하지 않습니다.
- 원본 step 파일이나 checkpoint bytes는 첨부되지 않았습니다. 로그가 보고한 내부 검사와
  로컬에서 확인한 결과 완결성/수치 일관성을 구분합니다.
