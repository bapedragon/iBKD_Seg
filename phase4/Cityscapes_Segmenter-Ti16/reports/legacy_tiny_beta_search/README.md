# 이전 Tiny β 탐색 기록 · 25batch 기준 후보 생성

2026-09-28 사용자 결정으로 후속 실험은 **L의 첫 step CE 비율에 맞춘 후보 4개**를 우선합니다.
기존 Tiny 결과·설정은 이 문서에서 모아 보존합니다. 원래 경로와 JSON을 유지하므로
이미 기록한 SHA-256·후보 선정 근거·재개 설정이 깨지지 않습니다.
기존 후보를 새 실험 후보로 이름만 바꿔 재사용하거나 두 탐색의 순위를 합치지 않습니다.

## CE 비율의 세 단계

| 구분 | 계산 또는 처리 | β/학습 변경 여부 |
|---|---|---|
| 기존 후보 생성 | 학습 전 25batch에서 CE와 guidance를 각각 측정하고 두 중앙값으로 β 계산 | 당시 후보를 생성 |
| 이후 표기 통일 | 이미 사용한 β를 첫 학습 batch의 `β × guidance / CE`로 환산 | **β·결과·후보 순위 변경 없음** |
| 새 L 비율 실험 | L 첫 step 실측 비율을 목표로 Tiny β를 새로 계산 | **새 후보·새 학습·별도 결과** |

기존 목표는 **1.5·3·4.5·6·9·12·18·24%**였습니다. 이를 첫 step 기준으로 환산하면:

| 후보 | LG·ALG | iBKD λ0.25 | iBKD λ0.5 |
|---:|---:|---:|---:|
| 1 | 1.461% | 1.467% | 1.466% |
| 2 | 2.923% | 2.933% | 2.932% |
| 3 | 4.384% | 4.400% | 4.399% |
| 4 | 5.845% | 5.866% | 5.865% |
| 5 | 8.768% | 8.799% | 8.797% |
| 6 | 11.690% | 11.732% | 11.730% |
| 7 | 17.535% | 17.598% | 17.594% |
| 8 | 23.380% | 23.465% | 23.459% |

모두 초기값이며 학습 중 이 비율을 유지한 것은 아닙니다. 초기 loss 비율이 gradient 크기나
최적 β를 보장하지 않습니다. 실제 후보 선정 기준은 **고정 2,000step 전체 val500 mIoU**였습니다.
과거 config/종료 JSON의 `initial_target_ratio`, `initial_ratio`는 **25batch 목표값**입니다.
후속 후보 7의 `initial_ratio_first_step_percent=17.5985`는 첫 step 실측값입니다.
[상세 계산·원본 근거](../initial_ce_ratio/README.md)와 [변경하지 않은 환산 JSON](../initial_ce_ratio/first_step_ratios.json)을 확인합니다.

## 완료와 미실행을 구분

- 500step: LG 공유 선별 8개 + iBKD λ0.25 8개 + λ0.5 8개 = **24개 완료**.
- 2,000step: LG 8개 + ALG 8개 + iBKD λ0.25 8개 + λ0.5 4개 = **28개 완료**.
  λ0.5는 후보 1·3·6·8만 2k를 했고 2·4·5·7은 생략했습니다. 실패한 것이 아닙니다.
- FSKD*·C2VKD*·Vanilla도 각각 2k 완료. 이를 포함한 2k 실행은 **31개**입니다.
- 10k: ALG 후보 7, iBKD λ0.25 후보 1·7, Vanilla = **4개 완료**.
  증류 상위 후보 8개 계획 중에는 **3개 완료**입니다.
- 기존 계획의 LG 7·1, ALG 1, iBKD λ0.5 1·6은 **10k 미실행으로 보존**합니다.
  새 비율 실험을 우선하며, 이전 계획을 자동으로 이어서 실행하지 않습니다.
